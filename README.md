# Classroom Designer

A free, installable web app (PWA) for designing pre-K classroom floor plans.

- 75+ pre-K furniture items drawn to real sizes (tables, cubbies, easels, sand & water table, play kitchen, rugs, cots…)
- Drag, resize, rotate, recolor, duplicate; snap to a 1-inch grid
- Text labels with pointer lines (callouts)
- Export to **Word (.docx)** with the floor plan, a list of centers, and a furniture list — or export a PNG image
- Autosaves in the browser; save/open layout files; works offline once installed

Hosted with GitHub Pages — no build step. All files sit at the repo root.
